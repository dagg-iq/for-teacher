# مِداد — خطة المشروع الكاملة

> «مِداد» تطبيق المدرّس العراقي: الصفوف والشعب، سجل الدرجات بالمعادلات، الإدخال الصوتي،
> الحضور، جدول الحصص، التحضير، والتقارير — في تطبيق واحد عربي، سريع، يعمل بلا إنترنت.

## ١. الهوية

| | |
|---|---|
| الاسم | **مِداد** (الحبر الذي يكتب به المعلم) |
| الشعار النصي | «دفترك كلّه، بصوتك.» |
| الرمز | ثلاثة أسطر أفقية (أسطر السجل) تقصر من اليمين لليسار، ونقطة حبر ملوّنة عند نهاية السطر الأخير = القلم وهو يكتب |
| اللون المميز | نيلي الحبر `#4338F0` (فاتح) / `#8F89FF` (غامق) |
| الخطوط | ثمانية (Sans للواجهة، Serif Display للعناوين والأرقام الكبيرة، Serif Text للقراءة) — نفس نظام «سعي» |
| القواعد | لون مميز واحد، بلا تدرجات، بلا إيموجي، زوايا 20–28، أيقونات خطية 1.8، أرقام عربية مشرقية، RTL كامل |

التفاصيل في `docs/BRAND.md`.

## ٢. البنية التقنية

```
apps/mobile        Expo SDK 57 + expo-router + TypeScript (أندرويد أولاً، يعمل على الويب للاختبار)
apps/site          الموقع التعريفي (HTML/CSS/JS) → Firebase Hosting
packages/shared    المنطق الصافي المختبَر: المعادلات، القوالب العراقية، التحليل الصوتي، الجدول، الإحصاء، المزامنة
supabase/          migrations + RLS + دوال (push) + اختبارات الصلاحيات
docs/              الخطة، الهوية، الإعداد، التقدّم
.github/workflows  CI، بناء APK، نشر الموقع، نشر Supabase، keepalive
```

**مبدأ البيانات: محلي أولاً (Offline-first)**
- كل البيانات تُحفظ على الهاتف فوراً (لا انتظار للإنترنت — شبكات العراق غير مستقرة).
- عند تسجيل الدخول: محرك مزامنة يرفع التغييرات ويسحب الجديد (آخر تعديل يفوز، حذف ناعم).
- يمكن استخدام التطبيق كاملاً بلا حساب، ثم إنشاء حساب لاحقاً لنقل البيانات للسحابة.

**Supabase**: تسجيل الدخول (بريد/كلمة سر + Google)، Postgres بجداول علائقية لكل كيان، RLS «المالك فقط»، عمود `synced_at` يضبطه الخادم للسحب التزايدي، دالة `push` للإشعارات.
**Firebase**: FCM للإشعارات البعيدة (إعلانات/تذكير)، Hosting للموقع والنطاق.
**الإشعارات المحلية**: تذكير قبل كل حصة، تذكير بالمهام والامتحانات.

## ٣. التبويبات (شريط سفلي بخمسة أقسام)

1. **الرئيسية** — تحية، الحصة الحالية/القادمة مع عدّ تنازلي، أرقام سريعة (الطلاب، الشعب، السجلات، نسبة النجاح)، آخر امتحان (المعدل، الناجحون/الراسبون، شريط النسبة)، طلاب يحتاجون متابعة، اختصارات (إدخال صوتي، سجل جديد، حضور اليوم، القرعة)، المهام القريبة.
2. **الصفوف** — صفوف ← شعب ← طلاب. إضافة الطلاب: لصق قائمة أسماء، استيراد Excel، يدوي. ملف الطالب: درجاته في كل السجلات، غياباته، ملاحظاته، رقم ولي الأمر (واتساب برسالة جاهزة).
3. **الدرجات** — سجلات الدرجات:
   - إنشاء سجل من قالب جاهز (عراقي) أو مخصّص: العنوان، الشعبة/الشعب، الأعمدة (إدخال أو معادلة)، الدرجة العظمى، قاعدة النجاح والتقديرات.
   - قوالب جاهزة: «السعي السنوي (إعدادي/متوسط)»، «ابتدائي من ١٠»، «امتحان شهري»، «اختبارات يومية»، «الدرجة النهائية مع الامتحان الوزاري».
   - منشئ معادلات سهل: معدل/مجموع/مرجّح/أعلى/أدنى بضغطة، أو كتابة معادلة حرة بأزرار للأعمدة، مع معاينة فورية.
   - جدول إدخال سريع (لوحة أرقام، انتقال تلقائي للطالب التالي، غائب/معفى).
   - **الإدخال الصوتي**: اختيار الشعبة + السجل + العمود، يقول «أحمد علي خمسة وثمانين» ← يتوجه للطالب ← بطاقة تأكيد بمؤقت ← تُكتب الدرجة. وضع «بالترتيب» (يقول الدرجات فقط). أوامر: تراجع، غائب، التالي، توقف. تحذيرات: درجة أكبر من العظمى، اسم غير معروف، تشابه أسماء، استبدال درجة موجودة. قراءة صوتية للتأكيد (اختياري).
   - إحصاءات: المعدل، الأعلى، الأدنى، نسبة النجاح، توزيع التقديرات، الأوائل.
   - تصدير Excel (من اليمين لليسار) وطباعة/PDF بترويسة رسمية (المدرسة، المادة، المدرس، الشعبة) وتوقيع.
4. **الجدول** — جدول الحصص الأسبوعي: معالج إعداد أول مرة (أيام الدوام، عدد الحصص، وقت البدء، مدة الحصة والفرصة)، شبكة جميلة، عرض اليوم، الحصة الحالية، تعديل، تذكير قبل الحصة، طباعة.
5. **المزيد** — الحضور والغياب، دفتر التحضير اليومي، المهام والتذكيرات، تقويم الامتحانات والمناسبات، القرعة واختيار المجموعات، مؤقت الحصة، تقارير الطالب، النسخ الاحتياطي (تصدير/استيراد)، الحساب والمزامنة، المظهر، عن التطبيق.
