# نَهج — خطة المشروع الكاملة

> «نَهج» تطبيق المدرّس العراقي: الصفوف والشعب، سجل الدرجات بالمعادلات، الإدخال الصوتي،
> الحضور، جدول الحصص، التحضير، والتقارير — في تطبيق واحد عربي، سريع، يعمل بلا إنترنت.

## ١. الهوية

| | |
|---|---|
| الاسم | **نَهج**: الطريق الواضح والمنهج |
| الشعار النصي | «التدريس بنهجٍ أذكى.» |
| الرمز | كلمة «نهج» بالخط الكوفي المربّع على شبكة ١١×١٣، الجيم بذيل ممتد، ونقطة النون خلية ذهبية؛ مع حركة «الحبر يسري» عند الفتح |
| الألوان | أخضر نَهج `#0E3B33`، الأخضر المائي `#0B6E5E`، الذهبي `#E3A535` (للخلية فقط)، الورق `#F7F5F0` |

التفاصيل في `docs/BRAND.md`.

## ٢. البنية التقنية

```
apps/mobile        Expo SDK 57 + expo-router + TypeScript (أندرويد، والويب للاختبار وللحاسوب)
apps/desktop       نسخة الحاسوب (ويندوز exe) عبر Electron من نفس الواجهة
apps/site          الموقع التعريفي (HTML/CSS/JS) → Firebase Hosting
server/            خادم مزامنة REST لقاعدة Oracle (بديل Supabase للبيانات) — docs/ORACLE.md
packages/shared    المنطق الصافي المختبَر: المعادلات، القوالب العراقية، التحليل الصوتي، الجدول، الإحصاء، المزامنة
supabase/          migrations + RLS + دوال (push) + اختبارات الصلاحيات
docs/              الخطة، الهوية، الإعداد، التقدّم
.github/workflows  CI، بناء APK، بناء الحاسوب، تحديث OTA، نشر الموقع، نشر Supabase، keepalive
```

**مبدأ البيانات: محلي أولاً (Offline-first)**
- كل البيانات تُحفظ على الهاتف فوراً (لا انتظار للإنترنت — شبكات العراق غير مستقرة).
- عند تسجيل الدخول: محرك مزامنة يرفع التغييرات ويسحب الجديد (آخر تعديل يفوز، حذف ناعم).
- يمكن استخدام التطبيق كاملاً بلا حساب، ثم إنشاء حساب لاحقاً لنقل البيانات للسحابة.

**طبقة السحابة قابلة للتبديل** (`apps/mobile/src/data/backends.ts`): Supabase مباشرة، أو خادم Oracle (`EXPO_PUBLIC_SYNC_BACKEND=rest`).
**Supabase**: تسجيل الدخول (بريد/كلمة سر + Google)، Postgres بجداول علائقية لكل كيان، RLS «المالك فقط»، عمود `synced_at` يضبطه الخادم للسحب التزايدي، دالة `push` للإشعارات.
**Firebase**: FCM للإشعارات البعيدة (إعلانات/تذكير)، Hosting للموقع والنطاق.
**الإشعارات المحلية**: تذكير قبل كل حصة، تذكير بالمهام والامتحانات.

## ٣. التبويبات — مكان واحد لكل شيء
(على الهاتف شريط سفلي، وعلى الحاسوب والشاشات العريضة شريط جانبي)

1. **الرئيسية** — التحية، الحصة الحالية/القادمة مع زرّي «الحضور» و«الدرجات» لشعبتها، أرقام سريعة (الطلاب، الشعب، الدرجات الحرجة، غياب اليوم)، اختصارات (الحضور، الدرجات، التقارير، التحضير، القرعة، المؤقت)، آخر سجل، طلاب يحتاجون متابعة، المهام القريبة.
2. **الصفوف** — صفوف ← شعب. **صفحة الشعبة** مركزها: ثلاثة أزرار (الحضور، الدرجات، التقرير) ثم قائمة الطلاب. ملف الطالب: درجاته بترتيب السنة، غياباته، ملاحظاته، رسالة لولي الأمر.
3. **الدرجات** — المكان الوحيد للسجلات: تختار الشعبة فتظهر سجلاتها بترتيب السنة.
   - **سجلات السنة** (`/book/year`): حقول الامتحان مرة واحدة (مثل تحريري ٦٠ + إنشاء ١٠ + شفهي ٣٠) فتُنشأ ٨ سجلات مترابطة:
     الشهر الأول والثاني لكل فصل، سعي الفصل = (الشهر الأول + الثاني) ÷ ٢، نصف السنة، السعي السنوي = (سعي ف١ + نصف السنة + سعي ف٢) ÷ ٣، واختيارياً النتيجة النهائية.
   - السعي يُحسب من السجلات نفسها (أعمدة «مرتبطة» بسجل آخر)، وكل سجل يُعدَّل: حقول إدخال، معادلات، أو «درجة من سجل آخر».
   - **سجل مخصص / امتحان بمكوّنات / درجة واحدة** للحالات الأخرى.
   - **الدرجات الحرجة**: إن وقعت درجة محسوبة في نطاق قريب من النجاح (مثلاً ٤٧–٤٩) يُنبَّه المدرس، ويرفعها إلى ٥٠ بعد موافقته فقط، مع التراجع؛ الدرجة الأصلية تبقى محفوظة.
   - **النتيجة ناجح/راسب فقط** (أُلغي التقدير).
   - الإدخال: على الهاتف «إدخال سريع» حقلاً حقلاً أو الجدول؛ على الحاسوب جدول واحد قابل للكتابة لكل الحقول (Enter/أسهم/Tab، «غ» للغائب).
   - **الإدخال الصوتي** من داخل السجل: «بالترتيب» (الأدق، الدرجات فقط) أو «الاسم + الدرجة»، احتمالات المحرك وتصحيح بلمسة، صيغ عامية للأعداد، بلا نطق آلي.
   - إحصاء السجل، تصدير Excel، طباعة/PDF بترويسة رسمية.
4. **الجدول** — جدول الحصص الأسبوعي مع التذكير والويدجت.
5. **المزيد** — **التقارير** (لكل شعبة: نتائج كل سجل، الراسبون، الدرجات الحرجة، الغياب، Excel بأربع أوراق وPDF)، الحضور والغياب (ضغطة = غائب، متأخر/مُجاز، سجل الأيام)، التحضير، المهام، القرعة، المؤقت، الحساب، الإعدادات، عن التطبيق.
