# هوية «مِداد»

- **الاسم:** مِداد — الحبر الذي يكتب به المعلم دفتره.
- **الشعار النصي:** «دفترك كلّه، بصوتك.»
- **الرمز:** ثلاثة أسطر من السجل تقصر نحو اليسار (اتجاه الكتابة العربية)، ونقطة حبر ملوّنة عند نهاية السطر الأخير = القلم وهو يكتب.
  ```svg
  <svg viewBox="0 0 120 120">
    <rect x="16" y="22" width="88" height="20" rx="10"/>
    <rect x="36" y="50" width="68" height="20" rx="10"/>
    <rect x="56" y="78" width="48" height="20" rx="10"/>
    <circle cx="34" cy="88" r="10" fill="ACCENT"/>
  </svg>
  ```
- **أيقونة التطبيق:** خلفية حبر `#111111`، أسطر بيضاء، نقطة `#8F89FF`. تُولَّد كلها بـ `python3 scripts/gen-icons.py`.

## الألوان (`packages/shared/src/theme.ts`)
| الدور | فاتح | غامق |
|---|---|---|
| الخلفية | #F5F5F2 | #0E0E0F |
| البطاقة | #FFFFFF | #18181A |
| الحبر | #111111 | #F2F2F0 |
| المميز (نيلي الحبر) | **#4338F0** | **#8F89FF** |
| خلفية المميز | #EEEDFF | #24224A |

ألوان النتائج فقط: ناجح/جيد أخضر، قريب برتقالي، راسب أحمر. ألوان تمييز الصفوف ثمانية هادئة (`classHues`).

## الخطوط
ثمانية (نفس نظام «سعي»): Serif Display للعناوين والأرقام الكبيرة، Sans لكل الواجهة، Serif Text للقراءة الطويلة.

## القواعد
لون مميز واحد، بلا تدرجات ولا ظلال ثقيلة ولا إيموجي، زوايا 20–28، أيقونات خطية 1.8، أهداف لمس ≥ 44،
أرقام عربية مشرقية، كل شيء من اليمين لليسار، حركة سريعة ≤ 220ms.
