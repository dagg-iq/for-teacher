# مِداد — دفترك كلّه، بصوتك.

تطبيق المدرّس العراقي: الصفوف والشعب والطلاب، سجلات الدرجات بالمعادلات والقوالب العراقية (السعي السنوي…)،
**إدخال الدرجات بالصوت**، الحضور والغياب، جدول الحصص مع التذكير، التحضير اليومي، القرعة والمؤقت،
وتصدير Excel وطباعة رسمية — يعمل بلا إنترنت، ومزامنة سحابية اختيارية.

| | |
|---|---|
| 📱 `apps/mobile` | التطبيق (Expo SDK 57 / React Native، أندرويد أولاً) |
| 🌐 `apps/site` | الموقع التعريفي (Firebase Hosting) |
| 🧮 `packages/shared` | المنطق المختبر: المعادلات، القوالب، فهم الكلام، الجدول، المزامنة |
| 🗄️ `supabase/` | قاعدة البيانات والصلاحيات (RLS) والدوال |
| 🧭 `docs/` | الخطة، الهوية، التقدّم، **وما يلزم منك للإطلاق** |

**ابدأ من:** [`docs/SETUP_TODO.md`](docs/SETUP_TODO.md)

```bash
npm ci
npm test                                   # اختبارات المنطق
npm run typecheck
cd apps/mobile && npx expo start           # تشغيل للتطوير
```
